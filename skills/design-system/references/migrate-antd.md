# Ant Design → DS

Remove `ConfigProvider` theme tokens and `antd` CSS imports once nothing uses them. Layout primitives
become `div` + Tailwind. Check every DS prop in https://design.blotout.io/api.md.

| Ant Design                                                                      | DS                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button type="primary" / default / "dashed" / "text" / "link"`, `danger`        | `Button variant='default' / 'outline' / 'outline' / 'ghost' / 'link'`, `'destructive'`                                                                                                                                       |
| `Button loading`, `icon`                                                        | `Button loading`, icon as child                                                                                                                                                                                              |
| `Input`, `Input.Password`, `Input.Search`, `Input.TextArea`                     | `Input`, `InputGroup` + `InputGroupPasswordToggle`, `InputGroup` + `SearchIcon className='size-4 shrink-0 text-muted-foreground'`, `Textarea`                                                                                |
| `Form` + `Form.Item` (`label`, `rules`, `help`)                                 | `Field invalid` + `FieldLabel` + control + `FieldError match`. DS has no validation engine: keep AntD's `Form` logic temporarily (marked TODO) or move rules to the app's existing form library if it has one; don't add one |
| `Select` (single)                                                               | `Select` (`items`) or `Combobox` when `showSearch`                                                                                                                                                                           |
| `Select mode="multiple" / "tags"`                                               | `Combobox multiple`                                                                                                                                                                                                          |
| `Checkbox`, `Checkbox.Group`, `Radio.Group`, `Switch`, `Slider`                 | `Checkbox`, `CheckboxGroup`, `RadioGroup`, `Switch`, `Slider`                                                                                                                                                                |
| `Radio.Group optionType="button"` / `Segmented`                                 | `ToggleGroup`                                                                                                                                                                                                                |
| `DatePicker`, `RangePicker`, `TimePicker`                                       | `DatePicker`, `DateRangePicker`, `TimePicker`                                                                                                                                                                                |
| `Upload`, `Upload.Dragger`                                                      | `FileUpload`, `Dropzone`                                                                                                                                                                                                     |
| `Table` (client data)                                                           | `DataTable`                                                                                                                                                                                                                  |
| `Table` with remote `pagination`/`onChange`                                     | `Table` family + `Pagination`                                                                                                                                                                                                |
| `Modal`, `Modal.confirm`                                                        | `Dialog`, `AlertDialog`                                                                                                                                                                                                      |
| `Popconfirm`                                                                    | `AlertDialog` (or `Popover` with two buttons for low-risk)                                                                                                                                                                   |
| `Drawer placement`                                                              | `Drawer direction`                                                                                                                                                                                                           |
| `message`, `notification`                                                       | `toast()`                                                                                                                                                                                                                    |
| `Alert type`                                                                    | `Alert variant` (`info` → `default`, `error` → `destructive`)                                                                                                                                                                |
| `Tag color`                                                                     | `Badge` by meaning (`success`, `alert`, `destructive`, `rest`, `secondary`)                                                                                                                                                  |
| `Badge count` / `dot`                                                           | `Badge type='number'` / `BadgeDot` / `AvatarBadge`                                                                                                                                                                           |
| `Tooltip`, `Popover`, `Dropdown` + `Menu`                                       | `Tooltip`, `Popover`, `DropdownMenu`                                                                                                                                                                                         |
| `Tabs`                                                                          | `Tabs`                                                                                                                                                                                                                       |
| `Collapse`                                                                      | `Accordion`                                                                                                                                                                                                                  |
| `Steps`                                                                         | `Stepper`                                                                                                                                                                                                                    |
| `Spin`                                                                          | `Spinner` (inline) / `Skeleton` (content)                                                                                                                                                                                    |
| `Skeleton`, `Progress`, `Avatar`, `Pagination`, `Breadcrumb`, `Card`, `Divider` | same-named DS components                                                                                                                                                                                                     |
| `Empty`, `Result`                                                               | compose (empty state snippet in build.md)                                                                                                                                                                                    |
| `Descriptions`                                                                  | `TableDetailList` + `TableDetailItem label=…`, or a `dl` grid with token classes                                                                                                                                             |
| `Statistic`                                                                     | `MetricText` (⚠️ percent values ×100)                                                                                                                                                                                        |
| `Timeline`                                                                      | `Timeline`                                                                                                                                                                                                                   |
| `Layout` + `Sider` + `Menu mode="inline"`                                       | `SidebarProvider` + `Sidebar` + `SidebarInset`                                                                                                                                                                               |
| `Layout.Header` + `Menu mode="horizontal"`                                      | `Navbar`                                                                                                                                                                                                                     |
| `Space`, `Row`/`Col`, `Flex`                                                    | `div` + `flex`/`grid` + `gap-*`                                                                                                                                                                                              |
| `Typography.Title/Text/Paragraph`                                               | type roles in [tokens.md](tokens.md)                                                                                                                                                                                         |
| `@ant-design/icons`                                                             | closest Lucide icon from the DS                                                                                                                                                                                              |

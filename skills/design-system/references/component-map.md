# Component map: need → DS component

Pick from this table first. Confirm props in the installed package's type definitions (typecheck or
editor go-to-definition); https://design.blotout.io/api.md is the quick reference (up to 0.1.3 it is
missing `PageHeader*` and `TabsList variant='header'`). Live list with Storybook links:
https://design.blotout.io/llms.txt

## App structure

| Need                                      | Use                                                                                                                                                                                                                                                                                                                                                                                           |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| App shell with left navigation            | `SidebarProvider` + `Sidebar` (+ `SidebarInset` for the content)                                                                                                                                                                                                                                                                                                                              |
| Top navigation bar                        | `Navbar` (+ `NavbarMobileMenu`)                                                                                                                                                                                                                                                                                                                                                               |
| Breadcrumb / page location                | `Breadcrumb`                                                                                                                                                                                                                                                                                                                                                                                  |
| Text link inside running text             | Plain `<a>` (or the router's `Link`) with `font-medium text-foreground underline underline-offset-4 hover:text-muted-foreground focus-visible:ring-3 focus-visible:ring-focus-ring rounded-sm outline-none`; there's no `TextLink`. Don't use `Button variant='link'` inline: it adds button height and padding                                                                               |
| Page header (title, description, actions) | `PageHeader` + `PageHeaderBanner`, `PageHeaderHeading` (`PageHeaderTitleRow` holding icon + `PageHeaderTitle` + `PageHeaderAddons`, then `PageHeaderDescription`), `PageHeaderActions` (0.1.3+; compose it before). Icon: `PageHeaderIcon` (24px) or `PageHeaderRoundIcon` (36px circle for brand marks). Status badge: `PageHeaderAddons`. Page-scope selector: first in `PageHeaderActions` |
| Sub-pages of an app (main view, settings) | Header tabs: `PageHeaderTabs` + `PageHeaderTabsList` + `TabsTrigger` (or `<TabsList variant='header'>`); one URL per tab. Never a button that jumps to the page                                                                                                                                                                                                                               |
| Tabs inside a section                     | `Tabs` (`<TabsList variant='line'>`)                                                                                                                                                                                                                                                                                                                                                          |
| Link to an external site                  | `Button variant='outline' nativeButton={false} render={<a target='_blank' rel='noreferrer' />}` + `ExternalLinkIcon` + `sr-only` "(opens in a new tab)"                                                                                                                                                                                                                                       |
| Command palette / quick search            | `CommandDialog` / `CommandPalette`                                                                                                                                                                                                                                                                                                                                                            |
| Date range filter                         | `DateRangePicker` (trigger + popover); inline panel: `CalendarPicker`                                                                                                                                                                                                                                                                                                                         |
| Resizable split panes                     | `ResizablePanelGroup`, `ResizablePanel`, `ResizableHandle`                                                                                                                                                                                                                                                                                                                                    |
| Scrolling region with styled scrollbar    | `ScrollArea`                                                                                                                                                                                                                                                                                                                                                                                  |
| Wizard / multi-step setup or onboarding   | `Stepper` + `Card` per step + your own Back/Continue buttons (pattern in build.md). `Questionnaire` is only for chat-style question-and-answer surveys, not setup wizards                                                                                                                                                                                                                     |

## Content and data

| Need                                                      | Use                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Surface / panel / widget                                  | `Card` (`CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, `CardFooter`)                                                                                                                                                                                                   |
| KPI / stat tile                                           | `Card size='sm'` + `MetricText` (with `change` for trend)                                                                                                                                                                                                                                          |
| Sortable, filterable, selectable table (client-side data) | `DataTable`                                                                                                                                                                                                                                                                                        |
| Read-only list with search and pages (no row selection)   | `Table` family + `Pagination` + `InputGroup` search (DataTable's footer always shows a selection count)                                                                                                                                                                                            |
| Server-paginated / server-sorted table                    | `Table` family + `Pagination` (`usePagination`)                                                                                                                                                                                                                                                    |
| Any table in a section                                    | `Table bordered` (0.1.3+) on its own, no `Card`; heading row above, notes below. Large size: `<Table bordered size='lg'>` once the installed `Table` has `size` (DS #33, after 0.1.3); until then one shared app component (build.md "Shared bordered table"); `DataTable` via `BorderedDataTable` |
| Table row actions                                         | Icon-only `Button variant='link' size='icon-sm' aria-label=…` + `Tooltip`; text label only when asked; all inline (overflow `DataTableRowActions` only when asked or more than four)                                                                                                               |
| Settings / configuration section                          | `<section>` row: title + description left (`lg:w-75`), headerless `Card className='flex-1 gap-4 p-4 md:p-6'` right (build.md)                                                                                                                                                                      |
| Per-item breakdown, expandable / tree rows                | Expandable table (`lg` size), never cards with "Show details": `TableRowGroup`, first cell `flex items-center gap-2.5` wrapper with `TableExpandToggle aria-label=…` first, then `TableCellContent`; `TableExpandedRow`, `TableDetailList` + `TableDetailItem label=…`; trees `TableTreeToggle`    |
| Section with title, filters, actions                      | Heading row above (`<h2>` + controls, search last), plain `Card` + `CardContent` below with only the data (build.md)                                                                                                                                                                               |
| List of rows with icon, title, actions                    | `ItemGroup` + `Item`                                                                                                                                                                                                                                                                               |
| Show/hide sections                                        | `Accordion` (many) / `Collapsible` + `CollapsiblePanel` (one)                                                                                                                                                                                                                                      |
| Event history / activity feed                             | `Timeline`                                                                                                                                                                                                                                                                                         |
| Status / count label                                      | `Badge`                                                                                                                                                                                                                                                                                            |
| User picture                                              | `Avatar`, `AvatarGroup`                                                                                                                                                                                                                                                                            |
| Dates and times in text                                   | `DateLabel`, `RelativeTime`                                                                                                                                                                                                                                                                        |
| Numbers / money / percent                                 | `MetricText`, `formatMetric`                                                                                                                                                                                                                                                                       |
| Image with loading/error states                           | `Image`                                                                                                                                                                                                                                                                                            |
| Charts                                                    | `Chart` (0.1.3+): `<Chart type='bar' data={rows} label='…' />` (types line/area/bar/pie/donut/funnel/scatter/sankey/radar/radial; confirm props in the types). Older versions: keep/use the app's chart lib coloured with `var(--chart-1…12)` and mark `TODO(design-system)`                       |
| Inline trend line (KPI tile)                              | `Sparkline` (0.1.3+): `<Sparkline data={[…]} label='…' />`                                                                                                                                                                                                                                         |

## Forms

| Need                                                   | Use                                                                                                                                                                                                                 |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Labelled field + help + error                          | `Field`, `FieldLabel`, `FieldDescription`, `FieldError match`; stack with `flex flex-col gap-4`; side-by-side pair: `grid gap-4 md:grid-cols-2` (`FieldGroup` only for a row that must stay side by side on mobile) |
| Checkbox/switch with inline label                      | `Field className='flex-row items-center gap-2'` + control + `FieldLabel`; rich rows `CheckboxCard`/`SwitchCard`                                                                                                     |
| Text / email / password                                | `Input`; addons and icons: `InputGroup` + `InputGroupInput`, `InputGroupPasswordToggle`, `InputGroupClear`                                                                                                          |
| Long text                                              | `Textarea` (`InputGroupTextarea` with addons)                                                                                                                                                                       |
| Pick one from a short list                             | `Select` (≤ ~15 options) or `RadioGroup` (2–5, all visible)                                                                                                                                                         |
| Pick from a long / searchable list, multi-select, tags | `Combobox`                                                                                                                                                                                                          |
| On/off setting                                         | `Switch` (applies instantly) / `Checkbox` (submitted with a form)                                                                                                                                                   |
| Rich option cards                                      | `RadioCard`, `CheckboxCard`, `SwitchCard`                                                                                                                                                                           |
| Date / range                                           | `DatePicker`, `DateRangePicker`, `CalendarPicker` (presets + timezone)                                                                                                                                              |
| Time                                                   | `TimePicker`                                                                                                                                                                                                        |
| Number in a range                                      | `Slider`                                                                                                                                                                                                            |
| Verification code                                      | `OTPField`                                                                                                                                                                                                          |
| File upload                                            | `FileUpload` (full flow) / `Dropzone` (just the drop area)                                                                                                                                                          |
| Segmented control                                      | `ToggleGroup`                                                                                                                                                                                                       |

## Actions and feedback

| Need                                    | Use                                                                         |
| --------------------------------------- | --------------------------------------------------------------------------- |
| Action                                  | `Button` (`loading` while pending)                                          |
| Joined buttons / split button           | `ButtonGroup`                                                               |
| Overflow "more" actions                 | `DropdownMenu` with an icon `Button` trigger                                |
| Right-click menu                        | `ContextMenu`                                                               |
| Confirm a destructive action            | `AlertDialog`                                                               |
| Modal task / form                       | `Dialog`                                                                    |
| Side panel / detail view / mobile sheet | `Drawer`                                                                    |
| Small anchored panel                    | `Popover`; on hover with rich content: `HoverCard`; plain hint: `Tooltip`   |
| Result of an action                     | `toast()` (`Toaster` mounted once)                                          |
| Inline message in a section             | `Alert`                                                                     |
| Page-wide announcement                  | `Banner`                                                                    |
| Loading                                 | `Skeleton` (content-shaped), `Spinner` (small inline), `Progress` (known %) |
| Keyboard key hint                       | `Kbd`                                                                       |

## Chat and AI

`Message`, `Bubble`, `PromptInput`, `Scroller`, `Suggestion`, `Sources`, `Tool`, `Marker`,
`Checkpoint`, `Attachment`. Use these for any assistant or chat surface; don't hand-build bubbles.

## Gap rule: when the DS has no component

1. Re-read this map and `llms.txt`: most "missing" components are a composition (empty state = `Item`/`Card` + icon + `Button`; page header = DS `PageHeader` (0.1.3+), otherwise compose it from a heading + `Breadcrumb` + `ButtonGroup`; stat tile = `Card` + `MetricText`).
2. Compose from DS parts and tokens in the app's own `components/` folder. Name it for what it is (`EmptyState`, `StatTile`), keep it thin, and don't fork or copy DS source.
3. Never pull in another UI library to fill the gap.
4. If it's generic enough that other apps will need it, tell the developer it's a candidate for the design system. Don't open issues or PRs; just list it in your summary.

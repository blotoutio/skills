# shadcn/ui and Radix → DS

The DS follows shadcn naming, so most of this is an import swap plus the Base UI API changes.
Imports: `@/components/ui/*` and `@radix-ui/*` → `@blotoutio/design-system`. Every trigger/child
`asChild` → `render` (see [gotchas.md](gotchas.md)).

| shadcn                                                                                                                                     | DS                                                                                                        | Change                                                                                                                                                                                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button`, `buttonVariants`                                                                                                                 | same                                                                                                      | `asChild` + `<Link>` → `nativeButton={false} render={<Link />}`, or `buttonVariants` on the link. `variant='default'/'secondary'/'outline'/'ghost'/'link'/'destructive'` same; manual spinner → `loading` |
| `Card*`                                                                                                                                    | same                                                                                                      | `CardAction` exists; `size='sm'` for compact. Remove radius/shadow overrides                                                                                                                              |
| `Input`, `Textarea`                                                                                                                        | same                                                                                                      | wrap in `Field`                                                                                                                                                                                           |
| `Label` + `Input`                                                                                                                          | `Field` + `FieldLabel` + `Input`                                                                          | drop `htmlFor`/`id` pairs                                                                                                                                                                                 |
| `Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormDescription`, `FormMessage`                                              | `Field` (`invalid`), `FieldLabel`, control, `FieldDescription`, `FieldError match`                        | keep react-hook-form; native inputs `register`, Base UI controls `Controller` (snippet in gotchas)                                                                                                        |
| `Select*`                                                                                                                                  | same part names                                                                                           | add `items` to `Select`; value may be `null`                                                                                                                                                              |
| `Accordion*`                                                                                                                               | same                                                                                                      | remove `type`/`collapsible`; `multiple` if `type="multiple"`; values become arrays                                                                                                                        |
| `ToggleGroup*`                                                                                                                             | same                                                                                                      | remove `type`; values become arrays                                                                                                                                                                       |
| `Toggle`                                                                                                                                   | same                                                                                                      | `pressed`/`onPressedChange`                                                                                                                                                                               |
| `Collapsible`, `CollapsibleTrigger`, `CollapsibleContent`                                                                                  | `Collapsible`, `CollapsibleTrigger`, `CollapsiblePanel`                                                   | rename content part                                                                                                                                                                                       |
| `Checkbox`                                                                                                                                 | same                                                                                                      | `checked="indeterminate"` → `indeterminate`                                                                                                                                                               |
| `Dialog*`                                                                                                                                  | same                                                                                                      | trigger `render`; long body in `DialogBody`                                                                                                                                                               |
| `AlertDialog*`                                                                                                                             | same                                                                                                      | trigger `render`; ⚠️ wrap Title + Description in `AlertDialogText` inside `AlertDialogHeader`; `AlertDialogAction variant='destructive'` for destructive confirms                                         |
| `Sheet*`                                                                                                                                   | `Drawer*`                                                                                                 | `<Sheet>` → `<Drawer direction='right'>` (`side` → `direction` on the root)                                                                                                                               |
| `Drawer` (vaul)                                                                                                                            | `Drawer` (`direction='bottom'`)                                                                           |                                                                                                                                                                                                           |
| `DropdownMenu*`, `ContextMenu*`, `Menubar*`                                                                                                | same                                                                                                      | ⚠️ item `onSelect` → `onClick`; `e.preventDefault()` to keep open → `closeOnClick={false}`                                                                                                                |
| `Popover*`, `HoverCard*`, `Tooltip*`                                                                                                       | same                                                                                                      | trigger `render`                                                                                                                                                                                          |
| `Command*` (cmdk)                                                                                                                          | `Command*` / `CommandDialog` / `CommandPalette`                                                           | ⚠️ `CommandItem onSelect` → `onClick`; or `CommandPalette` with `items[].onSelect`                                                                                                                        |
| `Badge`                                                                                                                                    | same                                                                                                      | `warning` → `alert`; custom colour classes → variant **by meaning** (`success` healthy/done, `alert` attention, `destructive` failed, `rest` inactive, `secondary` neutral labels like "Popular"/"New")   |
| `Alert`                                                                                                                                    | same                                                                                                      | `info` → `default`; add `warning`/`success` where the old one faked them with colours                                                                                                                     |
| `Sonner`, `toast` from sonner                                                                                                              | `Toaster`, `toast`                                                                                        | `toast.success('Saved', { description })` → `toast.success({ title: 'Saved', description })`; `duration` → `timeout`; `<Toaster richColors />` → `<Toaster />`                                            |
| `Table*`                                                                                                                                   | `Table*`                                                                                                  | client-side TanStack table → `DataTable` (rebuild columns with `createDataTableColumnHelper`; v9 types); server-side → keep `Table` + `Pagination`                                                        |
| `Tabs*`                                                                                                                                    | same                                                                                                      | style variant goes on `TabsList` (`variant='line'`)                                                                                                                                                       |
| `InputOTP`, `InputOTPGroup`, `InputOTPSlot`, `InputOTPSeparator`                                                                           | `OTPField`, `OTPFieldGroup`, `OTPFieldSlot`, `OTPFieldSeparator`                                          |                                                                                                                                                                                                           |
| `Calendar` + `Popover` date picker                                                                                                         | `DatePicker` / `DateRangePicker` / `CalendarPicker`                                                       |                                                                                                                                                                                                           |
| `Resizable*` (react-resizable-panels)                                                                                                      | `ResizablePanelGroup`, `ResizablePanel`, `ResizableHandle`                                                | check `direction` and size props in api.md                                                                                                                                                                |
| `Sidebar*`                                                                                                                                 | same                                                                                                      | `asChild` → `render`; active item `isActive`                                                                                                                                                              |
| `NavigationMenu*`                                                                                                                          | `Navbar` (app nav) or `Menubar`                                                                           | compose                                                                                                                                                                                                   |
| `Breadcrumb*`, `Pagination*`, `Avatar*`, `Progress`, `Separator`, `Skeleton`, `Slider`, `Switch`, `RadioGroup*`, `ScrollArea`, `Carousel*` | same                                                                                                      | check props in api.md (`Slider` values may be arrays)                                                                                                                                                     |
| `Chart*` (Recharts)                                                                                                                        | `Chart` only if installed version exports it                                                              | otherwise keep the chart, recolour with `var(--chart-N)`, mark TODO                                                                                                                                       |
| `Empty*`                                                                                                                                   | none                                                                                                      | compose (build.md snippet)                                                                                                                                                                                |
| `SelectScrollUpButton`, `SelectScrollDownButton`                                                                                           | none                                                                                                      | drop                                                                                                                                                                                                      |
| `DialogOverlay`, `DialogPortal`                                                                                                            | none                                                                                                      | drop: `DialogContent` portals and adds the backdrop                                                                                                                                                       |
| `PopoverAnchor`                                                                                                                            | none                                                                                                      | drop; Base UI positions against the trigger                                                                                                                                                               |
| `ScrollBar orientation='horizontal'`                                                                                                       | `ScrollArea orientation='horizontal' \| 'both'`                                                           |                                                                                                                                                                                                           |
| new shadcn `FieldSet`, `FieldLegend`, `FieldSeparator`, `FieldContent`, `FieldTitle`, `FieldGroup` (vertical)                              | `<fieldset>` + heading or a `Card` section; `Separator`; plain `div`; `FieldLabel`; `flex flex-col gap-4` | ⚠️ DS `FieldGroup` is columns, not a vertical stack                                                                                                                                                       |
| `Label` next to `Checkbox`/`Switch`                                                                                                        | `Field className='flex-row items-center gap-2'` + `FieldLabel`                                            |                                                                                                                                                                                                           |
| `globals.css` `:root`/`.dark` token blocks                                                                                                 | delete                                                                                                    | `theme.css` provides them                                                                                                                                                                                 |
| `lib/utils.ts` `cn`                                                                                                                        | `cn` from the DS                                                                                          | keep the local one only if non-UI code uses it                                                                                                                                                            |
